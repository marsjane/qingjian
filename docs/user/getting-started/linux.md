## 安装与启用

Linux 版本目前是需要从源码构建的 alpha 试用版，支持 Arch Linux 与 Omarchy。构建和安装步骤见仓库的 Linux 说明。

安装后重启 Fcitx5，在「输入法配置」中添加「青简」。若列表中未显示青简，取消「仅显示当前语言」后搜索。可与中州韵并存。

## 输入与选词

输入拼音后，候选旁显示英文或日文译词。`Space` 选择高亮候选，数字键选择当前页对应候选，鼠标也可选词。
`Enter` 原样输入拼音，`Esc` 取消尚未上屏的拼音。

`[`、`]` 或 `PageUp`、`PageDown` 翻页。上一／下一候选以及额外翻页键沿用 Fcitx5 的全局设置。
`Alt + 数字` 输入候选的第一条译词。中英切换沿用 Fcitx5 设置；已有左 `Shift` 切换配置时可继续使用。

可使用全拼或双拼。修改设置后需重启 Fcitx5。

## 试用范围

当前提供本地拼音转换、整句候选、单语言译词和基本选词偏好记忆。密码和敏感输入框中的按键直接交给应用。
切换应用或停用输入法时，尚未上屏的拼音会被取消。

云联想、本地神经重排、英文补全、注音、词汇统计和图形设置页尚未接入。
候选窗口的外观由 Fcitx5 管理。Linux 试用版不发送输入内容，也不保存输入内容日志。
